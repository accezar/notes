# Blog

Blog pessoal para compartilhar notas técnicas.

## Rotas

`https://accezar.github.io/blog/`

| Caminho | Página |
|---------|--------|
| `/` | Home (landing) |
| `/<slug>/` | Post individual |

## Comandos

Requisito: Node **22.12+** (conforme `package.json`).

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```
