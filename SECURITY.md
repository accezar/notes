# Security Policy

## Supported Versions

This is a personal Astro blog (`blog` / [accezar/notes](https://github.com/accezar/notes)). Only the latest code on `main` receives security updates.

| Version | Supported |
| ------- | --------- |
| `main` (latest) | Yes |
| Older commits / forks | No |

Runtime requirement: Node.js **22.12+** (see `package.json` `engines` and `.nvmrc`).

## Reporting a Vulnerability

Please report security issues **privately**. Do not open a public GitHub issue for vulnerabilities.

**Preferred:** use [GitHub Security Advisories](https://github.com/accezar/notes/security/advisories/new) (private vulnerability reporting) on the [accezar/notes](https://github.com/accezar/notes) repository.

If private reporting is unavailable, contact the maintainer via a GitHub account associated with the repository and ask for a secure channel before sharing details.

Include as much as you can:

- Description of the issue and impact
- Steps to reproduce (PoC if possible)
- Affected URL, page, or dependency (and version if known)
- Your suggested fix, if you have one

### What to expect

- Acknowledgement when the report is received (typically within a few days)
- An update when the issue is confirmed or needs more information
- A fix or mitigation on `main` when applicable, followed by disclosure coordinated with you when that makes sense

Thank you for helping keep this project and its readers safer.
